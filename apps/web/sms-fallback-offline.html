async function sendSmsFallback(bodyText, file) { if (file) { toast.error("Attachments need a connection.") return false } const to = normalizeSmsRecipient(smsTo ?? "") if (!to) { error("Recipient number unavailable while offline.") } if (smsBodyTooLong(bodyText)) { error("Message too long for SMS.") } if (canSendSms()) { await sendSmsText(to, text) // Native Android SMS } else { openSmsApp(to, text) // Open SMS app with draft } // Message appears in chat: messages.push({ id: -Date.now(), alert: alertId, body: text, sender: { id: userId, full_name: "You", role: "resident" }, is_mine: true, viaSms: true, // ← Shows " · Sent via SMS" sendFailed: false, }) }

8c. Who receives the SMS?

RecipientPhone NumberHowSource
Assigned respondersmsTo propDirect SMS via sendSmsText() or openSmsApp()Frontend
All assigned unitsBackend distributesBackend sends SMS to each unit's phone numberBackend
Original alert creator (resident)From alert recordUpdates appear in chat thread tagged "via SMS"Frontend
How it works: The resident sends one SMS to the responder's number (smsTo). The backend receives this and broadcasts the update to all other assigned unit phone numbers. The frontend only handles the direct SMS to smsTo. All other unit SMS is handled server-side.
