# Contributing to E-Boses

Thank you for your interest in contributing to E-Boses!

## How to Contribute

1. **Fork** the repository
2. **Create a branch** for your feature or fix:
   ```bash
   git checkout -b feat/your-feature-name
   ```
3. **Make your changes** following the project conventions
4. **Run tests** to ensure nothing is broken
5. **Commit** using conventional commit messages:
   ```bash
   git commit -m "feat: add your feature description"
   ```
6. **Push** and open a **Pull Request**

## Code Conventions

- **Frontend:** TypeScript, React functional components, Tailwind CSS, shadcn/ui
- **Backend:** Python, Django REST Framework, PEP 8
- **Commits:** [Conventional Commits](https://www.conventionalcommits.org/)
- **Branch names:** `feat/`, `fix/`, `docs/`, `chore/` prefixes

## Pull Request Checklist

- [ ] Code follows project conventions
- [ ] Tests pass
- [ ] New features include tests where applicable
- [ ] Documentation updated if needed
- [ ] No `console.log` or debug artifacts
